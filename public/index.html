                                                                  AI Search Patterns

                                                                  How Claude finds documents from natural language queries.

                                                                  "Find my latest proposal for Robert"
                                                                  name contains '[PROPOSAL]' and name contains 'Robert'
                                                                  "What did Stefan say in our last call?"
                                                                  name contains '[TRANSCRIPT]' and name contains 'Stefan'
                                                                  "Show me all active contracts"
                                                                  name contains '[CONTRACT]'
                                                                  "Prep me for my call with Jonathan"
                                                                  name contains 'Jonathan' and (name contains '[BRIEF]' or name contains '[TRANSCRIPT]')
                                                                  "Get the SOW template"
                                                                  name contains '[TEMPLATE]' and name contains 'SOW'
